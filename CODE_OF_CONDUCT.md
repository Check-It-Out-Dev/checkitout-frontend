# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful. Treat each other with dignity regardless of background,
identity, or experience level. Polish, English, and any other language
is welcome in discussions — we'll find a way to communicate.

## Enforcement

Report violations to **norbert_marchewka@checkitout.app**. All reports
are confidential. We'll acknowledge within 72 hours and act within the
guidelines of Contributor Covenant v2.1.
